# Hotel Management System (C++)

A simple console-based Hotel Management System written in C++. This project allows users to book a room, view customer details, and checkout.

## 🚀 Features

* Book a hotel room
* View customer details
* Checkout and display total bill
* Simple menu-driven interface

## 🛠️ Technologies Used

* C++
* Standard Library (`iostream`, `string`)

## 📋 How It Works

1. User selects an option from the menu:

   * Book Room
   * View Customer Details
   * Checkout
   * Exit
2. Room booking calculates bill based on ₹1000 per day.
3. Details are stored and displayed when requested.

## 📸 Sample Output

```

1. Book Room
2. View Customer Details
3. Checkout

```

## 📌 Notes

* This is a basic project for learning purposes.
* Stores only one customer's data at a time.
